# Northstar University — Week 5 Authentication & Access Control Playground

Standalone educational web app. Open `index.html` directly in a browser or upload both files to a GitHub Pages folder. No backend, real user accounts, or external dependencies.

Six practices: password security, authentication factors, MFA, IAM lifecycle, RBAC/least privilege, and authentication monitoring. All data is fictional; localStorage keeps progress and account changes in the same browser. Use **Reset all practices** to restore the initial state. The password lab does not store entered passwords.

Note: This is a teaching simulator, not a production authentication system or cryptographic password strength meter. Access-control rules are intentionally simplified.
