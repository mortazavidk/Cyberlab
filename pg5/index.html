2 · Authentication Factors

Identify something you know, have, or are. Two methods from the same factor do not necessarily constitute multi-factor authentication.

Challenge

Compare password + PIN with password + security key. Why is a passkey different from a traditional password?

Note: Real-world MFA classification depends on the implementation and independent verification of factors.

3 · MFA Login Simulation

Simulate a sign-in and investigate an unexpected push notification. Never approve a request you did not initiate.

Security insight

MFA adds protection against stolen passwords, but social engineering, session theft, and MFA fatigue can still create risks.
