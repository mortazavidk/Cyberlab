Cybersecurity Playground — CPSC 301 Week 4

Standalone cryptography playground with four independent modules:
1. AES-GCM encryption and decryption
2. TLS handshake and certificate validation simulation
3. SHA-256 hashing and integrity comparison
4. ECDSA digital signature creation and verification

DEPLOY TO GITHUB PAGES
Upload index.html to the root of a new repository and enable GitHub Pages from the main branch/root folder. Alternatively, upload this folder into an existing GitHub Pages repository to serve it at /cybersecurity-playground/.

LOCAL USE
Modern browsers expose the Web Crypto API in secure contexts (HTTPS or localhost). For local testing, from this folder run: python -m http.server 8000 and visit http://localhost:8000

No third-party scripts or services. Do not use real student information.
